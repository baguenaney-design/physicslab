## Key Equations
- $x = x_0 + v_0 \cos\theta \, t$ horizontal position
- $y = y_0 + v_0 \sin\theta \, t - \frac{1}{2} g t^2$ vertical position
- $v_x = v_0 \cos\theta$ horizontal velocity — constant
- $v_y = v_0 \sin\theta - g t$ vertical velocity
- $v = \sqrt{v_x^2 + v_y^2}$ speed
- $R = \dfrac{v_0^2 \sin 2\theta}{g}$ range, level ground
- $H = \dfrac{v_0^2 \sin^2\theta}{2g}$ maximum height
- $T = \dfrac{2 v_0 \sin\theta}{g}$ time of flight, level ground
